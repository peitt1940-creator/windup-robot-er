# 發條機器人急診室

國小三到六年級的合作溝通遊戲。2–4 人一組，限時 12 分鐘，加上回顧大約 15 分鐘。

## 玩法
玩具博覽會前一天，發條機器人「阿轉」故障了。修理員看得到阿轉，但沒有修理手冊；工程師拿著手冊，卻看不到阿轉。大家只能靠說話，修好齒輪組、發條盒、電線盒和胸口密碼鎖四個地方。修錯 3 次或時間到就要重修，每一輪的機器人狀態都會重新隨機產生。

- 修理員：用一台平板或電腦打開遊戲，選「我是修理員」。
- 工程師：用另一台裝置打開同一個網址，選「我拿手冊」，再勾選自己負責的手冊（齒輪本、發條本、電路本）。
- 2 人：1 位修理員＋1 位工程師（三本都拿）；3 人：1 位修理員＋2 位工程師；4 人：1 位修理員＋3 位工程師（每人一本）。
- 密碼鎖要三本手冊一起看才解得開。結局畫面附有回顧問題。

玩法結構改編自《Keep Talking and Nobody Explodes》（一人操作、其他人看手冊）；情境與規則全部重寫。
